## 2025-03-08 - Added Daily Process Tracking
**Learning:** HelperBoost is re-rendered frequently because it's a child of the Chat component, which has complex state (messages, input). Also, it has inline components (AnimatedChevron, CategorySection, QuestionItem) inside `HelperBoost.tsx` but defined *outside* the main component, which is fine, but they aren't memoized. The `handleQuestionClick`, `handleDrawerQuestionClick`, and `toggleVisibility` functions inside HelperBoost are re-created on every render, and the array mapping creates inline functions for onClick `onClick={() => handleQuestionClick(key)}`.
**Action:** Use `React.memo` for `HelperBoost`, `CategorySection`, and `QuestionItem`. Wrap functions in `useCallback` inside `HelperBoost`. This will prevent unnecessary re-renders of the helper buttons when typing in the chat input.
