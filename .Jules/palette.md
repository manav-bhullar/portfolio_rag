## 2026-08-31 - [Interactive Elements Accessibility in React]\n**Learning:** When creating custom trigger props for modal components in React, wrapping them in a clickable <div> creates poor UX for screen readers and keyboard users. Additionally, when using React.cloneElement with generic ReactNode types, TypeScript requires proper type casting to safely access and merge props like onClick to prevent build errors.\n**Action:** Use React.isValidElement and React.cloneElement to directly merge event handlers onto custom triggers instead of wrapping them. Ensure correct generic interface casting (e.g., as React.ReactElement<{onClick?: ...}>). Always replace clickable <div> elements with semantic <button type="button"> elements, providing aria-labels for icon-only buttons and robust focus-visible styles.
