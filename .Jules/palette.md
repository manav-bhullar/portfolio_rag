## 2024-10-26 - Project-Specific Focus States
**Learning:** The project uses specific, custom Tailwind classes (`outline-none focus-visible:border-ring focus-visible:ring-ring/50 focus-visible:ring-[3px]`) for keyboard focus states on interactive elements, defined in `src/components/ui/button.tsx`, rather than standard generic focus classes.
**Action:** Always check the project's design system (e.g., `button.tsx`) to ensure custom focus states match the repository's established UI standards when making accessibility improvements to raw or un-styled interactive elements.
